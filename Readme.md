# 📁 File Management System

A full-stack **MERN application** that allows users to **upload, manage, preview, and organize files** in a centralized platform.

The application supports multiple file types and provides a simple interface to handle file storage and retrieval efficiently. This project demonstrates full-stack development using **React, Node.js, Express, and MongoDB** with real-time features.

---

# 🚀 Features

## 📤 File Upload

* Upload files directly from the browser
* Supports multiple file formats

## 📂 File Management

* View uploaded files
* Organize stored files
* Delete and manage files

## 👀 File Preview

Supports preview for:

* Images
* Videos
* Audio files
* PDF documents

## 🔐 Authentication

* Secure login system
* Protected API routes

## ⚡ Real-Time Updates

* Implemented using **Socket.io**
* Updates appear instantly

## 🤖 AI Chatbot

* Integrated with **HuggingFace API**
* Helps users interact with the system

# ⚙️ Installation

## 1. Clone the repository

```
git clone https://github.com/Jayavardhan11/File-handling-project.git
```

## 2. Navigate into the project

```
cd File-handling-project
```

---

# 📦 Install Dependencies

### Backend

```
cd server
npm install
```

### Frontend

```
cd ../client
npm install
```

---

# 🔑 Environment Variables

Create a `.env` file inside the **server** folder.

Example:

```
PORT=5000
MONGO_URI=your_mongodb_connection_string
HUGGINGFACE_API_KEY=your_api_key
```

---

# ▶️ Run the Application

### Start Backend

```
cd server
npm start
```

### Start Frontend

```
cd client
npm start
```

Application will run on:

```
Frontend: http://localhost:3000
Backend: http://localhost:5000
```
